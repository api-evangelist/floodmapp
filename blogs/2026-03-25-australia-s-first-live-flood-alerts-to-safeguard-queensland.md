Queensland residents in Douglas and Fraser Coast can now receive live flood alerts via select GPS navigation apps. The Australian-first trial provides local drivers critical, real-time warnings about flood impacted roads, hazards and automatic route diversions to help reduce risk and save lives. The innovative alert system is powered by an intelligent modelling tool developed by Brisbane-based start-up FloodMapp.
